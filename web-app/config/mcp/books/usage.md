# Using The Greatest Books tools

Answer only from what the tools return. Do not fill gaps from memory.

- Cite each book you mention with its `url` from the tool result, so the person can open its page on the site.
- Keep rank order. The ranked book collections (`list_books`, the category books tools and the ranking configuration books tools) come best first, and a lower `rank` is better. `list_author_books` and `list_ranking_configuration_author_books` give an author's books ranked first in rank order, then the unranked ones (null `rank`). Other tools have their own order: `search_books` and `search_authors` are best match first (each hit still carries its primary `rank`), `list_similar_books` is most similar first, `list_list_items` follows the list's own `position`, and `list_book_lists` puts the weighted lists first, `search_categories` puts name matches before matches through an alternative name, `list_countries` is the country with the most ranked books first (or by name with `sort=name`), and `list_lists` with `sort=newest` is the most recently activated list first (the default `sort=weight` is heaviest first). Present results in the order the tool gave them and do not re-sort them.
- Check `total_count` in `meta`. When it is larger than the number of items you fetched, say so, for example "these are the top 50 of 1,200", and use the `page` and `limit` arguments if you need more.
- Report only ranks you fetched, and never invent a rank. If a book's `rank` is null, it is not ranked, and you should say that. If you did not fetch a rank, do not guess it.

For a question about one book, `find_book` returns the book and the lists that include it in one call. Use `search_books` first when the title is ambiguous. For an author's books, use `list_author_books` with the author's slug (from `search_authors`) instead of searching their name. To turn a name into a slug, do not guess one. `search_categories` finds category slugs by name (a genre, subject, setting or audience), and `list_countries` gives the country slugs; both return a `book_count` of ranked books, and a subject or setting with only a handful of ranked books is left out. Pass the slug to the `category_id` or `country_id` filter of `list_books`, or to `list_category_books`. `list_lists` takes `q` to find a list by name, source or URL. A `q` that is empty is an error, not a request for every list.

To answer where a book or a list stands on one particular ranking configuration, rather than the primary one, use the `get_ranking_configuration_book` tool (the book's `rank` there, null if that configuration does not rank it), `list_ranking_configuration_book_lists` (only the lists that configuration feeds, with its weights) and `get_ranking_configuration_list` (the list's `weight` there, null if the configuration does not feed it). Take the configuration `id` from `list_ranking_configurations`.

The `ranking-methodology` resource explains how lists are weighted into the ranking, what a ranking configuration is and what `rank` means; read it before answering a question about why a book ranks where it does.
