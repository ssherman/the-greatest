Tools for The Greatest Books: a catalogue of books ranked by combining many curated lists. Answer only from tool results. Cite each book you mention with its url, keep rank order (the ranked book collections arrive best first and a lower rank is better, while search_books is best match first and list_list_items follows the list's own order, so do not re-sort any of them), say when total_count exceeds the number of items you fetched, and never invent a rank (a null rank means the book is not ranked). For one book, find_book returns it with the lists that include it; read the ranking-methodology resource to explain why a book ranks where it does.
