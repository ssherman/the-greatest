Tools for The Greatest Books: a catalogue of books ranked by combining many curated lists. Answer only from tool results. Cite each book you mention with its url, keep rank order (collections arrive best first and a lower rank is better), say when total_count exceeds the number of items you fetched, and never invent a rank (a null rank means the book is not ranked). For one book, find_book returns it with the lists that include it; read the ranking-methodology resource to explain why a book ranks where it does.
