# Descriptions Subsystem — Increment (a): Model, Resolver, Concern — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a polymorphic `Description` model, a pure selection resolver, and a `Describable` concern wired into the eleven content models — with zero behaviour change to any existing page.

**Architecture:** `Description` is a polymorphic child record modelled on the existing `Image` and `ExternalLink` patterns, keyed on `(describable, kind, locale, source, source_name)`. Which description displays is *computed*, not flagged: `Descriptions::Resolver` takes a loaded collection and returns the `preferred` row, else the highest-priority `normal` row, never a `deprecated` one. Nothing reads or writes it yet — increments (b)–(e) backfill, then cut the write and read paths over.

**Tech Stack:** Rails 8.1.3, Ruby 3.4.7, PostgreSQL 17.4, Minitest + fixtures.

**Spec:** `docs/superpowers/specs/2026-07-27-descriptions-subsystem-design.md`

## Global Constraints

```ruby
class CreateDescriptions < ActiveRecord::Migration[8.1]
  def change
    create_table :descriptions do |t|
      t.references :describable, polymorphic: true, null: false
      t.integer :kind, null: false, default: 0
      t.string :locale, null: false, default: "en"
      t.integer :source, null: false
      t.string :source_name
      t.text :content, null: false
      t.integer :rank, null: false, default: 0
      t.string :source_url
      t.integer :license
      t.datetime :retrieved_at
      t.timestamps
    end

    # nulls_not_distinct is load-bearing: source_name is NULL on every non-:other row,
    # and Postgres treats NULLs as distinct by default, so without it this index would
    # accept two identical (describable, kind, locale, wikipedia, NULL) rows.
    add_index :descriptions,
      [:describable_type, :describable_id, :kind, :locale, :source, :source_name],
      unique: true, nulls_not_distinct: true,
      name: "index_descriptions_on_describable_and_key"

    add_check_constraint :descriptions,
      "source <> 9 OR source_name IS NOT NULL",
      name: "descriptions_other_requires_source_name"
  end
end
```

`t.references ... polymorphic: true` already adds the non-unique `[describable_type, describable_id]` index that `includes(:descriptions)` uses. `9` is the integer value of `source: :other`.

```ruby
  belongs_to :describable, polymorphic: true

  enum :kind, {summary: 0, long: 1, first_sentence: 2, blurb: 3}
  enum :rank, {deprecated: -1, normal: 0, preferred: 1}

  validates :source, uniqueness: {
    scope: [:describable_type, :describable_id, :kind, :locale, :source_name]
```

- [ ] **Step 3: Write the resolver**

Create `app/lib/descriptions/resolver.rb`:

```ruby
module Descriptions
  SOURCE_PRIORITY = %w[
    manual
    ai_generated
    goodreads
    wikipedia
    openlibrary
    publisher
    musicbrainz
    igdb
    other
  ].freeze

  class Resolver
    def self.call(descriptions, kind: :summary, locale: "en")
      candidates = descriptions.select do |description|
        !description.deprecated? &&
          description.kind == kind.to_s &&
          description.locale == locale.to_s
      end
      return nil if candidates.empty?

      pool = candidates.select(&:preferred?)
      pool = candidates if pool.empty?
      pool.min_by { |description| SOURCE_PRIORITY.index(description.source) || SOURCE_PRIORITY.size }
    end
  end
end
```

`select` rather than `reject`-then-`select` keeps it to one pass, and `min_by` over a preferred-first pool makes the result total and deterministic even if two `preferred` rows somehow coexist.

```ruby
module Describable
  extend ActiveSupport::Concern

  included do
    has_many :descriptions, as: :describable, dependent: :destroy
  end

  def primary_description(kind: :summary, locale: "en")
    Descriptions::Resolver.call(descriptions, kind: kind, locale: locale)
  end
end
```
