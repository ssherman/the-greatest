# Sitemaps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every app host serves an edge-cached, generated-on-request `/sitemap.xml` index plus child sitemaps listing its ranked items and hub pages, and `robots.txt` points at it.

**Architecture:** A registry maps each domain to a list of *sources*. A source knows its URL key, its count, and how to emit one page of `(path, lastmod)` entries from one `pluck` query. One `SitemapsController` (domain-constrained to books/music/games, like `/news`) renders the index and child files with XML builder views. `robots.txt` moves from `public/` to a `RobotsController` so it can append a per-host `Sitemap:` line. Everything is cached with `Cacheable#cache_for_show_page`, and no Cloudflare change is needed.

**Tech Stack:** Rails 8, Minitest + fixtures + Mocha, Jbuilder-free `.xml.builder` views (Builder ships with Rails), Playwright.

**Spec:** `docs/superpowers/specs/2026-11-12-sitemaps-design.md`

## Global Constraints

- All commands run from `web-app/`. Lint with `bundle exec standardrb`, not rubocop. No brakeman.
- Generate controllers with `bin/rails generate controller ... --skip-routes --no-helper`; delete the generated `.html.erb` views you replace.
- Absolute URLs come from `Api::Host.base_url(domain)`, **never** `request.base_url` (see `app/lib/api/host.rb`, `app/controllers/concerns/current_domain.rb`). *Deviation from the spec's "request.base_url" wording, recorded in the spec.*
- Item URLs are the canonical, non-`/rc/` paths: `/book/:slug`, `/author/:slug`, `/lists/:id` (books and games), `/album/:slug`, `/song/:slug`, `/artists/:slug`, `/albums/lists/:id`, `/songs/lists/:id`, `/game/:slug`, `/categories/:slug` (music and games), `/albums/categories/:slug`, `/news/:slug`.
- "Ranked" means a `RankedItem` with `rank IS NOT NULL` in `<RC class>.default_primary`. If `default_primary` is nil the source is empty, not an error.
- RC classes: `Books::RankingConfiguration` (books, lists), `Books::Authors::RankingConfiguration` (authors), `Music::Albums::RankingConfiguration`, `Music::Songs::RankingConfiguration`, `Music::Artists::RankingConfiguration`, `Games::RankingConfiguration`.
- Books and authors read through the `catalog` scope (`provisional: false`). Lists must be `status: :active` and have a `ranked_lists` row in the primary RC. Categories are `.active` (`deleted: false`).
- At most 50,000 URLs per child file: `Sitemaps::Registry::PAGE_SIZE = 50_000`. Order every source by `id` so URLs don't move between files from day to day.
- Thresholds (stubbable methods on `Sitemaps::Thresholds`): `filter_single` = 10 (books single category, single country; music categories; music album categories; games categories), `filter_pair` = 25 (books category + country).
- No year/date-range pages, no `/rc/` URLs, no collection-prefixed pages, no multi-category/country pages, no `/video-games` (duplicate of the games root).
- `lastmod` = `updated_at` (W3C datetime, `iso8601`) for items, lists and news posts. Static and filter/category pages omit it. No `priority`, no `changefreq`. *Checked:* ranking recalculation upserts `ranked_items` only and touches no item's `updated_at`.
- Index `<lastmod>` per child = the **source's** max `updated_at` (one cheap `maximum` query). Exact while each source is a single file, which all are today. *Spec deviation, recorded in the spec.*
- Books: when `Books::PublicIndexing.enabled?` is false, `Sitemaps::Registry.sources(:books)` is `[]`, so `/sitemap.xml` and every child 404 on books, and books `robots.txt` has no `Sitemap:` line. Tests stub `Books::PublicIndexing.stubs(:enabled?)`, never the env var.
- `robots.txt` rules stay byte-for-byte identical to today's `public/robots.txt`; the only addition is `Sitemap: <base_url>/sitemap.xml` as the last line when the host has sources.
- Inside `module Sitemaps; module Books`, refer to models as `::Books::Book` etc. (namespace shadowing).
- Minitest 6: `assert_nil`, never `assert_equal nil`. Check real fixture names before using them; they are semantic.
- No new gems, no Cloudflare change, no indexing change to any existing page.

## Review Focus

1. **A sitemap URL that renders `noindex`, 301s or 404s** (e.g. a category slug that is merged, a list that is ranked but inactive). Expected: never listed. Pinned by the Task 7 consistency test, which requests every listed URL on every host.
2. **Another host's source key** (`/sitemaps/songs-1.xml` on books) **or `page=0` / a page past the end.** Expected: 404, never another site's URLs or an empty 200. Pinned in Task 1.
3. **Books with the gate off.** Expected: `/sitemap.xml` 404, child 404, no `Sitemap:` line, while music/games are unaffected. Pinned in Tasks 1 and 6.
4. **Session cookie on a sitemap/robots response.** Expected: no `Set-Cookie`, `Cache-Control: public, max-age=86400`, or Cloudflare silently bypasses the cache. Pinned in Tasks 1 and 6.
5. **A ranked provisional book/author, or an unranked (`rank: nil`) ranked item.** Expected: excluded. Pinned in Task 2.

## File Structure

```
web-app/app/lib/sitemaps/
  entry.rb              # Sitemaps::Entry = Data.define(:path, :lastmod)
  thresholds.rb         # Sitemaps::Thresholds.filter_single / .filter_pair
  registry.rb           # Sitemaps::Registry.sources(domain) / .find(domain, key), PAGE_SIZE
  static_pages.rb       # fixed path list, no lastmod
  news_posts.rb         # NewsPost.<domain>.published
  ranked_items.rb       # generic: ranked items of one model in one primary RC
  ranked_lists.rb       # generic: active lists ranked in one primary RC
  ranked_categories.rb  # generic: active categories with >= minimum ranked items
  books/filter_pages.rb # books single category / country / pair pages
web-app/app/controllers/sitemaps_controller.rb
web-app/app/views/sitemaps/index.xml.builder, show.xml.builder
web-app/app/controllers/robots_controller.rb
web-app/app/views/robots/show.text.erb        # was public/robots.txt (git mv)
web-app/test/lib/sitemaps/...                 # one test per source + registry
web-app/test/controllers/sitemaps_controller_test.rb, robots_controller_test.rb
web-app/test/integration/sitemap_consistency_test.rb
web-app/test/fixtures/files/robots_rules.txt  # pinned copy of today's public/robots.txt
web-app/e2e/tests/music/sitemap.spec.ts, e2e/tests/games/sitemap.spec.ts
docs/features/sitemaps.md
```

**Source interface (every source class implements it):**

```ruby
# key      -> String matching /\A[a-z_]+\z/, unique per domain ("books", "album_lists")
# count    -> Integer
# entries(offset:, limit:) -> Array<Sitemaps::Entry>, ordered by id (or fixed order for static)
# lastmod  -> Time or nil (max updated_at over the whole source; nil when not tracked)
```
